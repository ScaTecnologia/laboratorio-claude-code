Gestão de Estoque — Reservas Redis

Como funciona a reserva de estoque

Black Friday sem overselling: quando um cliente inicia o checkout, o sistema reserva as unidades no Redis por 10 minutos usando um script Lua atômico. Se o pagamento não for concluído, a reserva expira automaticamente e o estoque volta a ficar disponível para outros clientes.

Coluna "Reservado (Redis)" = unidades bloqueadas para checkouts em andamento. Coluna "Disponível" = Estoque − Reservado = o que realmente pode ser vendido agora.
